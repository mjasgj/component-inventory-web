连接你的 GitHub 库存

网页只连接你的私有仓库，真实库存不会放到公开网页里。

如何获得访问令牌？
  1. 在 GitHub 创建一个有有效期的 fine-grained token。
  2. 仓库范围只选择你的私有库存仓库。
  3. 权限选择 Contents：Read-only；Issues：Read and write。Metadata 会自动附带。
  4. 生成后只粘贴到上面的框中，点击连接。
前往 GitHub 创建令牌 ↗

令牌仅保存在当前页面内存中，刷新或关闭页面后需重新连接；不会写入网址、浏览器存储、代码或日志。请求只发给 GitHub API。
