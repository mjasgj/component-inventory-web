# 元件柜 · 库存工作台

纯静态 HTML/CSS/JavaScript 网页，无构建依赖。支持输入型号即时筛选、点选器件出入库、库存预览、器件详情及流水。

## 使用

- 未连接时显示明确标识的演示数据；演示操作只改变内存。
- 点击“连接私有库存”（手机可点击顶部状态标记）连接自己的 GitHub 私有库存仓库。
- 使用限于库存仓库的、有有效期的 fine-grained token：Contents 只读、Issues 读写、默认 Metadata 只读。不要授权 Contents 写入或其他仓库。
- 令牌只保留在当前网页内存，关闭或刷新后重新连接；不存储到浏览器、URL 或代码。仅发送到 `api.github.com`。
- 网页只提交库存单据；库存数据库仍由私有仓库的受权限保护工作流修改。无需为网页提供数据库写入权限。
- 输入搜索关键词即时过滤已同步的快照；出入库仍需等待 GitHub Actions 云端确认。页面会展示单据处理进度并刷新库存，未知结果不会自动重复提交。

建档只要求型号。出入库只要求选择器件和数量。标题、内部编号和操作类别自动生成。新器件建档后库存为零，收到实物后再入库。

网页源代码可放在公开仓库。**不要将数据库、reports/、真实库存导出、令牌或私有仓库的其他文件复制到此公开仓库。**

## 部署

把本目录内容复制至单独的网页仓库根目录，GitHub Pages 设置为 main 分支 / 根目录。无需部署服务器，不需要安装 npm 依赖。可通过网址片段 `#repo=用户名/私有仓库名` 预填连接位置，不能在 URL 放令牌。

## 本地维护

```text
python -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.js
```

不在 public Pages 内存放真实数据。GitHub API 限流、Actions 免费额度和服务故障仍可能影响同步；以单据最终结果为准。
